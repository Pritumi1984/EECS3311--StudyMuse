# StudyMuse — AI Study Agent (EECS3311 Course Project)

StudyMuse is a Java desktop study assistant: a student uploads course materials, and an AI agent turns them into summaries, answers, flashcards, quizzes, weak-topic analysis and a personalized study plan. It has a JavaFX GUI and a command-line interface that share the same back end.
